# Retail Sales Data Analysis

## Project Overview
An exploratory data analysis project investigating simulated retail transactions using Python.

## Objectives
- Calculate retail sales KPIs and statistical summaries.
- Compare sales across product categories and regions.
- Examine monthly sales trends.
- Compare new and returning customer transactions.
- Explore correlations and potential outliers.
- Develop business recommendations based on the analysis.

## Dataset
The dataset contains 500 simulated transactions with order dates, regions, product categories, quantities, unit prices, customer types and sales values.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn and Google Colab.

## Visualizations
- Sales by category
- Sales by region
- Monthly sales trends
- Units sold by category
- Sales by customer type
- Correlation heatmap
- Sales outlier boxplot
- Category sales by region

## Key Deliverables
- Jupyter notebook
- CSV dataset
- Eight visualization images
- Business insights report

## Limitations
The dataset is simulated and does not represent actual retailer performance. Findings are intended for learning and require validation with real transaction data before business use.
